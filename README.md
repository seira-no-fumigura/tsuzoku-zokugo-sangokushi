## 作品について

『続後三国志』の江戸時代の和訳。尾田玄古（京都の儒者・医者）が正徳 2 年（1712 年）に撰した『通俗続後三国志』で、首巻（姓氏）と、前編・後編の巻之一から巻之三十二までを収める（西晋から東晋の事）。明治 45 年（1912 年）に早稲田大学出版部が『通俗二十一史』の第 7 巻として出した。国立国会図書館の目次の字のままの見出しが付く。巻頭の例言・両晋系譜・東晋年表と目次（早稲田大学編輯部）、序は入れていない。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
